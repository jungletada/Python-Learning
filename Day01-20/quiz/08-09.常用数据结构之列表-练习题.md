### 第 1 题：索引与切片（读程序写结果）

**考查点**：正向索引、反向索引、切片 `[start:end:stride]`、负数跨度、切片赋值

阅读下面的代码，写出每一行 `print` 的输出结果。

```python
nums = [10, 20, 30, 40, 50, 60, 70]
print(nums[2])          # ①
print(nums[-2])         # ②
print(nums[1:4])        # ③
print(nums[::3])        # ④
print(nums[-1:-4:-1])   # ⑤
print(nums[::-1])       # ⑥
print(nums[5:2])        # ⑦
print(nums[3:100])      # ⑧
nums[1:3] = [0]
print(nums)             # ⑨
print(len(nums))        # ⑩
```

**思考**：如果执行 `print(nums[7])` 会发生什么？为什么 ⑧ 中的 `100` 已经超出了列表范围却没有报错？

### 第 2 题：列表的方法（读程序写结果）

**考查点**：`append`、`insert`、`remove`、`pop`、`del`、`index`、`count`、`sort`、`reverse`，以及 `+`、`*` 运算

阅读下面的代码，写出每一行 `print` 的输出结果。

```python
items = ['Python', 'Java', 'Python', 'Go']
items.append('Rust')
items.insert(0, 'C')
items.remove('Python')
print(items)                    # ①
x = items.pop()
y = items.pop(1)
print(x, y)                     # ②
print(items)                    # ③
print(items.index('Go'))        # ④
print(items.count('Python'))    # ⑤
items.sort()
print(items)                    # ⑥
items.reverse()
print(items)                    # ⑦
del items[0]
print(items + ['Java'] * 2)     # ⑧
```

**思考**：如果在最后再执行一句 `items.remove('Swift')` 会怎样？应该如何改写才能让程序更安全？

### 第 3 题：列表生成式

**考查点**：列表生成式的基本语法、带条件的生成式、嵌套生成式

请**只用一行列表生成式**完成下面各小题：

1. 生成 `1` 到 `20` 之间所有偶数的平方构成的列表。
2. 已知 `words = ['apple', 'fig', 'banana', 'kiwi', 'cherry']`，生成由长度大于 `4` 的单词构成的列表。
3. 对同一个 `words`，生成由每个单词长度构成的列表。
4. 将下面的代码改写成列表生成式：

    ```python
    nums = [3, -1, 8, 0, -5, 12]
    result = []
    for n in nums:
        if n > 0:
            result.append(n * 10)
    print(result)
    ```

5. 用嵌套的列表生成式生成如下所示的 3 行 4 列的嵌套列表（第 `i` 行第 `j` 列的值为 `i * j`，`i`、`j` 都从 `1` 开始）：

    ```
    [[1, 2, 3, 4], [2, 4, 6, 8], [3, 6, 9, 12]]
    ```
