### 第 1 题：索引与切片（读程序写结果）

```
① 30
② 60
③ [20, 30, 40]
④ [10, 40, 70]
⑤ [70, 60, 50]
⑥ [70, 60, 50, 40, 30, 20, 10]
⑦ []
⑧ [40, 50, 60, 70]
⑨ [10, 0, 40, 50, 60, 70]
⑩ 6
```

- ⑤⑥：跨度为负数时，切片从 `start` 开始**向左**取元素，`[::-1]` 是得到反转列表的常用写法。
- ⑦：跨度默认为 `1`（向右取），但起始位置 `5` 已经在终止位置 `2` 的右边，所以取不到任何元素，得到空列表。
- ⑧：切片运算对越界的位置是“宽容”的，超出范围的部分会被自动截断，不会报错。
- ⑨：切片赋值时，右边列表的元素个数可以和被替换的元素个数不同，这里用 1 个元素替换了 2 个元素，列表长度因此变为 `6`。
- **思考题**：`nums[7]` 是索引运算，有效索引只有 `0` 到 `6`（或 `-1` 到 `-7`），越界会引发 `IndexError: list index out of range`。

### 第 2 题：列表的方法（读程序写结果）

```
① ['C', 'Java', 'Python', 'Go', 'Rust']
② Rust Java
③ ['C', 'Python', 'Go']
④ 2
⑤ 1
⑥ ['C', 'Go', 'Python']
⑦ ['Python', 'Go', 'C']
⑧ ['Go', 'C', 'Java', 'Java']
```

- ①：`remove` 只会删除**第一个**匹配的元素，所以第二个 `'Python'` 被保留了下来。
- ②：`pop()` 不传参数时删除并返回最后一个元素；`pop(1)` 删除并返回索引为 `1` 的元素。
- ⑥：字符串排序是按字符的编码逐个比较的，`'C' < 'G' < 'P'`。
- ⑧：`*` 的优先级高于 `+`，先得到 `['Java', 'Java']`，再与 `items` 拼接。
- **思考题**：`'Swift'` 不在列表中，`remove` 会引发 `ValueError`。安全的写法是先用成员运算判断：

```python
if 'Swift' in items:
    items.remove('Swift')
```

### 第 3 题：列表生成式

```python
# 1. [4, 16, 36, 64, 100, 144, 196, 256, 324, 400]
squares = [i ** 2 for i in range(1, 21) if i % 2 == 0]

words = ['apple', 'fig', 'banana', 'kiwi', 'cherry']
# 2. ['apple', 'banana', 'cherry']
long_words = [w for w in words if len(w) > 4]
# 3. [5, 3, 6, 4, 6]
lengths = [len(w) for w in words]

# 4. [30, 80, 120]
nums = [3, -1, 8, 0, -5, 12]
result = [n * 10 for n in nums if n > 0]

# 5. [[1, 2, 3, 4], [2, 4, 6, 8], [3, 6, 9, 12]]
table = [[i * j for j in range(1, 5)] for i in range(1, 4)]
```

> **提示**：第 5 小题中，内层生成式 `[i * j for j in range(1, 5)]` 负责生成“一行”，外层生成式负责把这样的行重复生成 3 次，这和课程中随机生成 5 个学生 3 门课成绩的写法是一样的。

### 第 4 题：嵌套列表 —— 学生成绩统计

```python
names = ['关羽', '张飞', '赵云', '马超', '黄忠']
courses = ['语文', '数学', '英语']
scores = [[95, 83, 92], [80, 75, 82], [92, 97, 90], [80, 78, 69], [65, 66, 89]]

# 1. 每个学生的总分和平均分，同时记录总分用于第 3 问
totals = []
for i in range(len(names)):
    total = 0
    for score in scores[i]:
        total += score
    totals.append(total)
    print(f'{names[i]}: 总分 {total}, 平均分 {total / len(courses):.1f}')

# 2. 每门课程的最高分和最低分（按“列”遍历）
for j in range(len(courses)):
    max_score = min_score = scores[0][j]
    for i in range(1, len(scores)):
        if scores[i][j] > max_score:
            max_score = scores[i][j]
        if scores[i][j] < min_score:
            min_score = scores[i][j]
    print(f'{courses[j]}: 最高分 {max_score}, 最低分 {min_score}')

# 3. 总分最高的学生
best = 0
for i in range(1, len(totals)):
    if totals[i] > totals[best]:
        best = i
print(f'总分最高的是{names[best]}, 总分 {totals[best]}')
```

> **说明**：`scores[i]` 取到的是第 `i` 个学生的成绩（一“行”），而某门课程的所有成绩是一“列”，需要固定 `j`、让 `i` 变化，即 `scores[i][j]`。学过内置函数后，这里也可以用 `sum`、`max`、`min` 简化，例如 `max([row[j] for row in scores])`。

### 第 5 题：综合应用 —— 掷两颗色子

```python
import random

counters = [0] * 11
for _ in range(6000):
    face1 = random.randrange(1, 7)
    face2 = random.randrange(1, 7)
    # 点数之和为 2 到 12，对应索引 0 到 10
    counters[face1 + face2 - 2] += 1

max_index = 0
for index in range(len(counters)):
    total = index + 2
    print(f'{total:>2d}点: {counters[index]:>4d}次 {"*" * (counters[index] // 50)}')
    if counters[index] > counters[max_index]:
        max_index = index
print(f'出现次数最多的点数之和是: {max_index + 2}')
```

> **说明**：
> - 关键在于建立“点数之和”和“列表索引”之间的映射关系：`索引 = 点数之和 - 2`，反过来 `点数之和 = 索引 + 2`。
> - `"*" * n` 利用了字符串的重复运算，和列表的 `*` 运算是同一个道理。
> - 多运行几次你会发现，点数之和为 `7` 的次数几乎总是最多，因为两颗色子组成 `7` 的组合有 6 种（1+6、2+5、3+4、4+3、5+2、6+1），而组成 `2` 或 `12` 的组合都只有 1 种。
